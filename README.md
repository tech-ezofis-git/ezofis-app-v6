# Ezofis V6 - Monorepo

Welcome to the Ezofis V6 Repository.

## Repository Structure

```
ezofis-app-v6/
├── app/    # Front-End Application (React + Vite + Capacitor)
└── api/    # Back-End Services & API Source Code
```

### Front-End (`/app`)
- **Framework**: React 19, TypeScript, Vite, Tailwind CSS, Mantine, TanStack Router
- **Mobile Support**: Capacitor (iOS & Android)
- **Commands**:
  ```bash
  cd app
  npm install
  npm run dev
  ```

### Back-End (`/api`)
- **API Services**: Maintained by the Back-End engineering team.

### Agents (/agents)
- Synced from [AIorchestrator](https://github.com/tech-ezofis-git/AIorchestrator)
- Console UI: /console  Chat API: POST /chat`r
